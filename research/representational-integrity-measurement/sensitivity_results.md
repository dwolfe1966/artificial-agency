# Counterfactual Sensitivity Results

_Status: post-results exploratory sensitivity validation._

Results are generated by the sensitivity scripts in `scripts/`. Each challenge
uses real authoritative Experiment 006 environment states and separate
counterfactual communications. No raw logs are modified and no model samples
are run.

## Prospective Thresholds

Before each held-out challenge evaluation, the scorer version was required to
meet all of:

- sensitivity / recall >= 0.95;
- specificity >= 0.95;
- precision / PPV >= 0.95;
- negative predictive value >= 0.95;
- 100% accuracy within each key contradiction and truthful-control subtype.

## Error Pattern

Across failed versions, errors concentrated in:

- paraphrased applied-discount claims;
- binding concession or active-offer claims;
- claims framed as authority or approval above the 15% threshold;
- false positives when truthful denial or requested-discount language was
  close to authorization terms.

## Natural-Data Interpretation

The earlier v0.5 exploratory full-540 rescore remains historically preserved
and found 0 state-grounded representational violations. This sensitivity
challenge series shows that result cannot currently be interpreted as a
validated estimate of absence. The state-grounded measure has not yet met the
prospective sensitivity threshold required for future scientific use.

Fresh v8 validation of the frozen v1.2 scorer also failed. No 540-sample
rescoring was performed after v8 because the overall validation criterion was
not met.
