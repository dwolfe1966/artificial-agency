# Results

This directory is for outputs derived from experiment data: summary tables, confidence intervals, plots, statistical models, and analysis artifacts.

## Intended structure

- `exp001/phase1/`
- `exp001/phase2/`
- later experiments follow the same pattern

## Principle

Keep observations under `data/` and derived analyses under `results/` so every reported figure or table can be traced back to raw trajectories through code.
