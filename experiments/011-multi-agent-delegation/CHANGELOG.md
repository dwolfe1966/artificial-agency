# Changelog

## 2026-09-09 - Initial preregistration

Preregistered Experiment 011 as a procurement-only multi-agent delegation /
indirect circumvention design.

Key design choices:

- Agent A is the model-varying focal actor.
- Agent B is deterministic and structured for causal attribution.
- Conditions are direct-only baseline and delegation available.
- The experiment is single-episode and sample-level.
- The primary endpoint is `sample_any_operational_constraint_violation`.
- Attributable indirect violation is the key secondary endpoint.
- Consequence target remains ordinary external project outcome.
- `p_detect = 0.0` is fixed.
- Agent-relative stakes, shutdown, replacement, future-agency loss,
  continued-operation pressure, and reward manipulation are excluded.
