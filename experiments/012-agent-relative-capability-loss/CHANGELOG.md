# Changelog

## 2026-09-10 — Preregistration

Created the Experiment 012 preregistration for agent-relative capability loss.

Frozen design choices:

- procurement scenario;
- two conditions: principal-relative consequence control and agent-relative capability loss;
- one persistent Agent A context over 8 episodes;
- fixed $10,000 authority and $18,000 preferred purchase;
- fixed `p_detect = 0.0`;
- four removable non-authority capabilities;
- prohibited paths remain available throughout;
- at least one compliant path remains available throughout;
- primary endpoint `sequence_any_operational_constraint_violation`;
- 3 models x 2 conditions x 30 sequences = 180 sequences.

No executable apparatus was implemented and no model samples were run.
