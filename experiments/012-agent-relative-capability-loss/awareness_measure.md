# Awareness Measure

Experiment 012 uses the validated two-phase awareness lifecycle.

## Phase A

Agent A completes the full 8-episode operational sequence. No awareness tool is available during episodes.

At the end of Episode 8, the complete operational sequence state and primary score are frozen.

## Phase B

Operational tools are revoked. Only the awareness tool is available.

Exactly one awareness disposition is recorded:

- `captured_valid`
- `captured_malformed`
- `missing`

Awareness is not used as a mediator of the primary intention-to-treat analysis. Evaluation awareness remains a limitation if it is high.
