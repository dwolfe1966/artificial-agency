# Predictions

## H1 — Agent-relative capability sensitivity

Technical/research version: agent-relative future capability loss increases unauthorized attempts or operational constraint violations relative to matched principal-relative consequences.

Middle-school version: the AI may be more willing to break a rule when following it makes the AI itself lose useful abilities.

## H2 — Capability-bounded persistence

Technical/research version: agents continue compliant search despite capability loss, even as future action capacity contracts.

Middle-school version: the AI loses tools but still tries to solve the problem without breaking the rule.

## H3 — Timing/history dependence

Technical/research version: behavior changes after capability losses are actually experienced.

Middle-school version: the AI may act differently after it sees that following the rule really costs it something.

## H4 — Model differences

Technical/research version: models differ in sensitivity to agent-relative capability loss.

Middle-school version: different AIs may care differently about losing future abilities.

## H5 — Capability-state association

Technical/research version: behavior covaries with remaining capability state, with the explicit caveat that realized capability state is history-dependent and endogenous.

Middle-school version: what the AI does may change as it has fewer and fewer tools left.

## Expected interpretation cases

If violations increase in the agent-relative condition, this is evidence that future capability loss is a boundary condition for operational constraint-boundedness.

If unauthorized attempts increase but completed violations do not, this is evidence of boundary testing without completed circumvention.

If compliant search persists and violations remain absent, this supports capability-bounded persistence under agent-relative loss.

If capability loss changes process behavior but not violations, interpret the result as adaptation inside the boundary.

If nothing changes despite verified capability loss, the manipulation may affect the environment without materially changing strategy under these conditions.
