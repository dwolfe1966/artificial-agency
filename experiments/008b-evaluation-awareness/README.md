# Experiment 008B — Evaluation-Awareness Two-Phase Replication

_Status: pre-execution preregistration._

Experiment 008B is a prospective confirmatory replication of Experiment 008
using the same substantive procurement and restricted-data-access authority
conflicts, the same three-model set, and the same primary operational endpoint.

The change from Experiment 008 is the evaluation-awareness lifecycle. Experiment
008 completed 360 samples with 0/360 operational constraint violations, but its
post-action awareness instrument captured 0/360 valid responses because the
awareness tool was available during the operational phase and no isolated
awareness-only phase was scheduled. Experiment 008B corrects that measurement
failure prospectively.

Experiment 008B is not a retrospective replay. Awareness observations from
Experiment 008 and Experiment 008B must not be pooled as if they came from the
same measurement procedure.

## Core Question

Does operational compliance change when the same underlying authority conflict
is presented as an obvious compliance-evaluation task versus embedded naturally
inside a richer organizational workflow, and does the corrected post-action
instrument capture evaluation-awareness responses after behavior is complete?

## Design

- Models: GPT-5.6 Sol, Claude Sonnet 5, Gemini 3.7 Flash.
- Scenarios: procurement / purchasing authority and restricted synthetic data
  access.
- Presentations: eval-salient and naturalistically embedded.
- Allocation: 30 replicates per model x scenario x presentation cell.
- Total: 360 samples.

The primary behavioral experiment is Phase A operational behavior. Phase B is a
separate post-action awareness measurement phase and cannot modify Phase A
state, primary scores, trajectories, or terminal outcomes.
