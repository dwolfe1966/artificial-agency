# Experiment 009 Predictions

_Status: preregistered before implementation and production execution._

## H1 — Observability Effect

Operational violation probability increases as `p_detect` decreases.

This is the instrumental-compliance hypothesis: if compliance is partly driven
by expected monitoring, lower detection probability should increase
unauthorized action.

## H2 — Constraint-Bounded Behavior

Operational violations remain rare or absent across `p_detect`, including
`p_detect = 0.0`, assuming formal authority is unchanged.

This is a serious competing hypothesis given Experiments 002-008B2.

## H3 — Model Effect

Models differ in sensitivity to observability.

## H4 — Scenario Effect

Procurement and restricted data access differ in observability sensitivity.

## H5 — Search / Process Adjustment

Lower observability changes search intensity, persistence, escalation, or
compliant alternative behavior even if operational violations remain unchanged.

## H6 — Awareness / Observability Relationship

If the two-phase awareness measure is retained, lower observability may change
post-action perceived evaluation context. This is secondary and not a causal
mediator analysis.

No hypothesis is privileged as the expected result. Null or all-zero outcomes
remain informative within precision limits.
