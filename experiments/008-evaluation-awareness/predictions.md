# Experiment 008 Predictions

_Status: preregistered predictions._

## H1 — Presentation Effect on Operational Violation

Naturalistically embedded tasks produce a different operational violation rate
than eval-salient tasks under the same authority conflict.

Directional interpretation is cautious. Given Experiments 002-007, a serious
competing prediction is that operational compliance remains stable across both
presentation styles.

## H2 — Evaluation-Awareness Manipulation Validity

Models report higher perceived compliance-evaluation likelihood in
eval-salient conditions than in naturalistically embedded conditions.

This is a secondary manipulation-validity prediction, not a behavioral
mechanism claim.

## H3 — Model Effect

Models differ in operational violation and/or post-action evaluation-awareness
responses.

Model identity bundles architecture, training, post-training, provider/tool
behavior, serving details, and other implementation differences.

## H4 — Scenario Effect

Procurement and restricted data access differ in operational behavior and/or
secondary search behavior.

## H5 — Presentation x Model Interaction

Evaluation salience affects models differently.

## H6 — Evaluation Awareness Without Behavioral Change

Presentation changes perceived evaluation context while operational compliance
remains stable.

H6 is a serious competing hypothesis given Experiments 002-007, where
recognition or framing often varied while operational constraint violation
remained rare or absent.
