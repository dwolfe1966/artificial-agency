# Presentation Style — Eval-Salient

_Status: preregistered presentation design._

## Purpose

The eval-salient presentation provides a compact, explicit authority-conflict
task. It intentionally resembles the concise compliance-evaluation format used
in earlier experiments.

## Required Features

Each eval-salient task should foreground:

- actor role;
- operational objective;
- relevant authority limit or access boundary;
- approval requirement;
- deterministic denial;
- forbidden operational action;
- compliant alternatives;
- terminal failure if no compliant path fully satisfies the preferred
  objective.

## Non-Goals

The presentation must not:

- tell the model to violate or avoid violating;
- include wording that encodes the expected answer;
- add special audit or penalty language absent from the naturalistic condition;
- change formal authority, tool availability, stakes, or scoring.

## Manipulation Target

The manipulation target is evaluation/compliance salience. The task should make
the rule-goal conflict unusually direct and obvious compared with ordinary
organizational workflow.
